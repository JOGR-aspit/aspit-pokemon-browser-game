# Pokédex image sources

The eight PNG files in this folder are local copies of the `official-artwork` images from the [PokeAPI sprites repository](https://github.com/PokeAPI/sprites). They were downloaded on September 22, 2026.

The repository's [license notice](https://github.com/PokeAPI/sprites/blob/master/LICENCE.txt) states that the image content is copyright The Pokémon Company. This instructor example uses the files for a noncommercial learning project.

Each source image is a transparent `475 × 475` PNG. The HTML records those intrinsic dimensions, and `styles.css` controls the flexible rendered size.
